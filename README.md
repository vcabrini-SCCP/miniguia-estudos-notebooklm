# 🏈 miniguia-estudos-notebooklm

Projeto desenvolvido como parte do bootcamp, atuando como um guia focado na trajetória, estatísticas e legado do melhor jogador de todos os tempos da NFL: **Tom Brady**.

## 📌 Funcionalidades
* Compilação de dados históricos sobre a carreira de Tom Brady.
* Análises estruturadas utilizando o NotebookLM.
* Insights sobre estratégias e recordes da NFL.

## 🛠️ Tecnologias e Ferramentas
* [NotebookLM](https://notebooklm.google) - Ferramenta de IA para organização de estudos.
* Markdown - Formatação da documentação.

## 🚀 Como Utilizar
1. Acesse o material de estudos na pasta principal do repositório.
2. Utilize as fontes fornecidas para fazer perguntas personalizadas no NotebookLM.
